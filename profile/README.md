## 🚀 Sobre a TSCBr

A **TSCBr — Technology Solution Company** desenvolve soluções digitais focadas em transformar processos, necessidades operacionais e ideias em produtos tecnológicos funcionais.

Nossa atuação envolve desde aplicações web completas até automações, ferramentas desktop, integrações, banco de dados e projetos de impacto social.

**CNPJ:** 58.714.576/0001-09

### Áreas de atuação

- 💻 Desenvolvimento de software
- 🌐 Sistemas e plataformas web
- ⚙️ Automação de processos
- 📊 Dados e bancos de dados
- 🔗 Integrações entre sistemas
- 🏢 Soluções corporativas
- 🤝 Tecnologia aplicada a projetos sociais

# 🧩 Soluções e ferramentas

## 💿 Install Office

**Aplicação desktop criada para automatizar e padronizar etapas da instalação do Microsoft Office utilizando recursos oficiais da Microsoft.**

A versão atual foi reescrita em C# e WPF e trabalha com Office Deployment Tool, verificações de segurança, validação do instalador e confirmação do resultado da instalação.

`C#` `.NET` `WPF` `PowerShell` `Windows APIs` `Office Deployment Tool`

**Status:** 🟢 Em uso · Código público disponível

# 🤝 Tecnologia com impacto social

Além de produtos próprios e soluções corporativas, a TSCBr também participa do desenvolvimento de tecnologia aplicada a projetos voluntários e sociais.

## ❤️ Evangelismo Solidário — IEADPE

Sistema desenvolvido para apoiar uma ação social da IEADPE, organizando cadastro de participantes, controle de presença por atividade e consolidação dos atendimentos realizados.

A solução real foi utilizada na ação e uma versão demonstrativa sanitizada é mantida publicamente para portfólio.

`HTML` `CSS` `JavaScript` `LocalStorage`

**Status:** ✅ Projeto concluído · 🧪 Demo pública
