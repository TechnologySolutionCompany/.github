A **TSCBr — Technology Solution Company** desenvolve soluções digitais para transformar processos, necessidades operacionais e ideias em produtos tecnológicos funcionais.

Nossa atuação envolve aplicações web, ferramentas desktop, automações, integrações, dados, banco de dados e projetos de impacto social.

# 🧩 Soluções e ferramentas

## 💿 Install Office

**Aplicação desktop para automatizar e padronizar etapas da instalação do Microsoft Office utilizando recursos oficiais da Microsoft.**

A versão atual foi reescrita em C# e WPF e trabalha com Office Deployment Tool, verificações de segurança, validação do instalador e confirmação do resultado.

`C#` `.NET 10` `WPF` `PowerShell` `Windows APIs` `Office Deployment Tool`

**Status:** 🟢 Em uso · 🌐 Código público disponível
